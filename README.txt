휘블록스 사이트 (잿빛 저택 · 턴제 카드 · 새싹 모험기 + 멀티플레이 서버)
=====================================================================

폴더 구성
  server.js      ← 사이트 + 멀티플레이 서버 (이거 하나가 둘 다 해요)
  package.json   ← 필요한 부품 목록 (ws)
  public/        ← 휘블록스 사이트 파일
    index.html   ← 휘블록스 첫 화면
    sprout.html  ← 새싹 모험기
    ash.html, g3d.html, ch1.html ← 잿빛 저택
    games/deck.html, covers/deck.jpg ← 턴제 카드

---------------------------------------------------------------------
1) 내 컴퓨터에서 먼저 해 보기
---------------------------------------------------------------------
  1. https://nodejs.org 에서 Node.js(LTS)를 설치해요.
  2. 이 폴더에서 터미널(명령 프롬프트)을 열고:
       npm install
       npm start
  3. 브라우저에서 http://localhost:3000 을 열어요.
  4. 창을 두 개 열고 각각 새싹 모험기에 들어가면 서로 보여요!
     (같은 와이파이의 다른 기기는 http://내컴퓨터IP:3000 으로 접속)

---------------------------------------------------------------------
2) 인터넷에 올려서 어디서든 같이 하기 (예: Render 무료)
---------------------------------------------------------------------
  1. GitHub에 새 저장소를 만들고 이 폴더 안의 파일을 전부 올려요.
     (node_modules 폴더는 올리지 않아도 돼요)
  2. https://render.com 가입 → New + → Web Service → 그 저장소 선택
  3. 설정:
       Runtime        : Node
       Build Command  : npm install
       Start Command  : npm start
       Instance Type  : Free
  4. Create 를 누르면 몇 분 뒤 https://○○○.onrender.com 주소가 생겨요.
  5. 그 주소를 친구에게 보내면 와이파이·데이터·거리와 상관없이 같은 서버에서 만나요.

  * Railway, Fly.io 같은 다른 Node 호스팅도 같은 방법으로 돼요.
  * Render 무료 서버는 한동안 아무도 없으면 잠들어요. 처음 들어갈 때 30초~1분쯤 걸릴 수 있어요.
  * 서버를 껐다 켜도 캐릭터는 각자 브라우저에 저장돼 있어서 그대로예요.

---------------------------------------------------------------------
3) 서버 없이 사이트만 (GitHub Pages, Netlify 등)
---------------------------------------------------------------------
  public 폴더 안의 파일만 올려도 게임은 돼요. 다만 이때는 멀티플레이 없이 혼자 플레이예요.
  멀티 서버를 다른 곳(Render 등)에 따로 올렸다면, public/sprout.html 의 <head> 바로 아래에
     <script>window.SPROUT_WS='wss://내서버주소.onrender.com/ws'</script>
  한 줄을 넣으면 그 서버로 접속해요.

알아 두기
  - 캐릭터 저장은 각자 브라우저(기기)에 돼요. 다른 기기에서는 새로 만들어야 해요.
  - 채팅·귓속말은 서버를 거쳐 가요. 비밀번호 같은 건 채팅에 쓰지 마세요.
  - 휘블록스의 휘벅스·듀얼 매칭·공유 랭킹은 Claude 안에서만 되는 기능이라,
    자체 사이트에서는 각자 기기에만 저장돼요.
